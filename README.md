# 天机·星盘 Lite (Tianji Astrology Lite)

天机·星盘 Lite 是一款现代化的命理排盘与分析工具，结合了传统八字算法与 Google Gemini AI 技术，旨在为用户提供清晰、深度且个性化的命理分析体验。

## ✨ 核心功能

### 1. 🗂️ 智能档案管理
- **多用户支持**：轻松创建和管理多个命盘档案。
- **真太阳时校正**：支持经度输入，自动校正出生时间为真太阳时，确保排盘精准。

### 2. 🔮 专业八字排盘
- **四柱展示**：精准计算年、月、日、时四柱干支。
- **专业参数**：包含十神、纳音、十二长生、胎元、命宫及身宫等详细命理信息。
- **生肖解析**：基于生肖的本命特征快速概览。

### 3. 📊 五行能量分析
- **可视化图表**：
  - **雷达图**：直观展示五行（金、木、水、火、土）旺衰对比。
  - **环形图**：清晰呈现五行能量分布比例。
- **强弱判定**：结合月令智能分析日元强弱。

### 4. 📅 运程追踪系统
- **大运排布**：自动推算起运岁数及每十年大运。
- **流年分析**：支持逐年运势查看，包含流年风险检测提醒。
- **时间轴交互**：通过直观的时间轴快速切换不同运势周期。

### 5. 📜 神煞详查
- 系统化列出命局中的关键神煞（如桃花、驿马、魁罡、太极贵人等），辅助深度断命。

### 6. 🤖 AI 智算解读 (Powered by Gemini)
- **智能报告**：集成 Google Gemini AI，根据排盘数据生成通俗易懂的综合运势报告。
- **个性化建议**：提供事业、情感、财运等方面的针对性建议。
- **隐私安全**：API Key 本地存储，保障用户数据隐私。

## 🚀 快速开始

### 1. 环境准备
确保您的系统已安装 [Node.js](https://nodejs.org/) (建议版本 v18+)。

### 2. 安装依赖
在项目根目录下运行终端命令：

```bash
npm install
```

### 3. 配置环境变量
项目需要 Google Gemini API Key 才能使用 AI 解读功能。
1. 在项目根目录创建或修改 `.env.local` 文件（如果不存在）。
2. 添加以下内容（`VITE_` 前缀确保前端可见）：
   ```env
   VITE_GEMINI_API_KEY=your_api_key_here
   ```
   > 💡 **提示**: 用户也可以在应用界面的设置中直接输入 API Key，它将保存在浏览器的 LocalStorage 中。

### 4. 启动开发服务器
```bash
npm run dev
```
启动成功后，浏览器访问 `http://localhost:3000` 即可使用。

## 📖 使用指南

1. **新建档案**：点击侧边栏的“+”号，输入姓名、性别、出生日期及地点。
2. **查看排盘**：选择档案后，点击“开始排盘”查看四柱信息及五行分析。
3. **AI 解读**：切换到“AI 解读”标签页，点击生成报告获取详细运势预测。
4. **运势切换**：在“运程”标签页点击不同的大运或流年，查看具体时间段的运势详情。
